# Новички: где мы их теряем

**Открыть:** https://bestmark1.github.io/novichok/

Каждый третий из ушедших у вас не доработал до трёх месяцев. Это среднее по компании — а потери обычно сосредоточены в нескольких местах.
Эта страница показывает **где именно** теряются новички и **с кем из нынешних новичков стоит поговорить на этой неделе**, пока они не ушли.

Сделано для HR и руководства. Работает на выгрузке задач Битрикс24 «Приём: ФИО» и «Увольнение: ФИО», которые у вас уже есть.

## Как посмотреть и оценить за 3 минуты

Откройте ссылку — сразу загрузятся демо-данные вымышленной компании, похожей на вашу (склады, магазины, отдел продаж, офис; ~240 приёмов за 2 года).

1. **Верх страницы** — сколько новичков не дорабатывает до 90 дней (в демо 33%, как «каждый третий») и на какой неделе обычно уходят.
2. **«На этой неделе: с кем поговорить»** — конкретные люди младше 90 дней, которые попали туда, где новички уходят чаще всего, и ещё не прошли «опасные» недели. У каждого: почему он в списке, кто должен поговорить (если проблема в самом руководителе — HR), три вопроса для разговора и отметка «Поговорили».
3. **«Где теряем новичков»** — места, где ранний уход выше, чем в остальной компании, и это не случайность. В демо это «Склад №2» с одним руководителем (уходят 70% против 28%) и канал найма «Авито» (57% против 25%). Нажмите «Люди в этом срезе», чтобы увидеть, кто и когда ушёл.
4. **«Выглядит плохо, но данных мало»** — например, «Интернет-магазин: ушли 2 из 3». Страница честно не делает вывод по трём людям.
5. **«Как это считается и чего здесь нет»** — внизу страницы, простыми словами.

## Как попробовать на своих данных

Кнопка **«Загрузить выгрузку задач из Битрикс24 (CSV)»**. Файл обрабатывается **только в вашем браузере** и никуда не отправляется — у страницы нет сервера.

Нужны колонки: `Название` (задачи вида «Приём: ФИО» / «Увольнение: ФИО»), `Сотрудник`, `Подразделение`, `Должность`, `Руководитель`, `Канал найма`, `Дата события` (ДД.ММ.ГГГГ), `Причина увольнения`. Разделитель `;`, кодировка UTF-8 или windows-1251 (как выгружает Битрикс24).
В вашем портале эти поля, скорее всего, — пользовательские поля задачи; их названия может понадобиться сопоставить. Пример файла: [`data/demo.csv`](data/demo.csv).

## Чего страница не делает

- Не объясняет, **почему** люди уходят: показывает, где смотреть.
- Не учитывает уходы последних 90 дней в процентах: исход по ним ещё неизвестен, поэтому свежий провал виден с задержкой.
- Ищет проблемные места по одному признаку (отдел, руководитель, должность, канал, сезон), а не по сочетаниям вроде «магазины, нанятые летом».
- Отметка «Поговорили» хранится только в браузере, где её поставили.

## Для разработчика

Чистые HTML + JS, без сборки и зависимостей. Расчёты — `src/analysis.js` (точный тест Фишера, поправка Бенджамини–Хохберга по уникальным срезам), интерфейс — `src/app.js`.

```bash
python3 -m http.server 8000          # локальный запуск, открыть http://localhost:8000
node --test tests/*.test.mjs         # 12 тестов; тест Фишера сверен со scipy
node scripts/generate.mjs > data/demo.csv   # пересоздать демо-данные
```
